# ASIR2-SRI-texto

Repositorio de GitHub con un libro de texto completo en formato Markdown que incluye los materiales didácticos del módulo **Servicios en Red e Internet (SRI)** de **2.º de CFGS Administración de Sistemas Informáticos en Red (ASIR)**.

El repositorio contiene los contenidos y recursos utilizados para desarrollar las distintas unidades de trabajo del módulo, incluyendo documentación técnica, ejemplos, configuraciones y materiales de apoyo para las prácticas.

**Repositorio:**
