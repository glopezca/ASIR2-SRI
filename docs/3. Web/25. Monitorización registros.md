# 25. Monitorización del servicio y visualización de registros

## Objetivos
- Aprender a monitorizar el estado de un servidor web y sus servicios.
- Interpretar los registros de acceso y error del servidor.
- Identificar y solucionar problemas utilizando logs y herramientas de monitorización.

---

## 25.1 Monitorización básica del servicio

### Verificar si Apache está activo
```
sudo systemctl status apache2
```

### Recargar la configuración sin detener el servicio
```
sudo systemctl reload apache2
```

### Reiniciar Apache completamente
```
sudo systemctl restart apache2
```

---

## 25.2 Visualización de registros

Apache mantiene dos registros principales:

### **Registros de acceso**
Contienen información sobre cada solicitud:
- dirección IP del cliente  
- recurso solicitado  
- código de estado HTTP  
- agente de usuario  

Ubicación:
```
/var/log/apache2/access.log
```

### **Registros de error**
Incluyen:
- errores del servidor  
- problemas de configuración  
- fallos en scripts o módulos  

Ubicación:
```
/var/log/apache2/error.log
```

### Ver registros en tiempo real
```
sudo tail -f /var/log/apache2/access.log /var/log/apache2/error.log
```

---

## 25.3 Herramientas de monitorización

### **top**
Muestra en tiempo real:
- uso de CPU  
- consumo de memoria  
- procesos activos  

### **htop**
Versión mejorada, más visual e interactiva.
Instalación:
```
sudo apt install htop
```

### **GoAccess**
Analiza tráfico web y genera informes HTML.

Instalación:
```
sudo apt install goaccess
```

Generar un reporte:
```
goaccess /var/log/apache2/access.log -o reporte.html
```

El archivo `reporte.html` contendrá estadísticas detalladas del servidor.

---

## 25.4 Resolución de problemas

### Revisar registros de error
Buscar mensajes que indiquen:
- permisos incorrectos  
- archivos no encontrados  
- sintaxis inválida en configuraciones  

### Validar configuración de Apache
```
sudo apache2ctl configtest
```
Si está todo correcto:
```
Syntax OK
```

### Probar solicitudes con curl
```
curl -I http://localhost
```

---

## 25.5 Automatización y alertas

Implementar monitorización avanzada con sistemas como:

### **Nagios**
Permite:
- supervisar el estado del servidor,
- configurar alertas vía email o SMS,
- monitorear servicios, almacenamiento y red.

Instalación básica:
```
sudo apt install nagios
```

### **Zabbix**
Otra plataforma robusta para monitorización continua, dashboards y alertas.

---

## 25.6 Recomendaciones generales
- Revisar los logs regularmente.
- Automatizar informes diarios/semanales.
- Mantener backups de configuraciones.
- Usar herramientas visuales para análisis de tráfico intensivo.
