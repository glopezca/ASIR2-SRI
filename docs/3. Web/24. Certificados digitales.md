# 24. Gestión de certificados digitales en servidores web

## Objetivos
- Entender el concepto de certificados digitales y su importancia en la seguridad web.
- Aprender a generar e instalar certificados digitales en un servidor Apache.
- Configurar HTTPS para garantizar conexiones seguras.

---

## 24.1 ¿Qué es un certificado digital?
Un **certificado digital** es un archivo emitido por una **Autoridad de Certificación (CA)** que asocia una clave pública a la identidad de su propietario.

Sirve para:
- validar la identidad de un servidor,
- cifrar comunicaciones mediante SSL/TLS,
- garantizar integridad y autenticidad.

---

## 24.2 Proceso de gestión de certificados

El proceso común para instalar certificados en Apache incluye:

### 1. Generar clave privada
```
openssl genrsa -out ejemplo.com.key 2048
```

### 2. Generar CSR (Solicitud de firma de certificado)
```
openssl req -new -key ejemplo.com.key -out ejemplo.com.csr
```
La CSR contiene:
- dominio,
- organización,
- ubicación,
- correo de contacto.

### 3. Obtener certificado firmado
La CA devuelve un archivo:
- `ejemplo.com.crt`
- junto con la cadena de certificados (`chain.crt`)

### 4. Configurar Apache para HTTPS

Editar el archivo del sitio:
```
SSLEngine on
SSLCertificateFile /etc/ssl/certs/ejemplo.com.crt
SSLCertificateKeyFile /etc/ssl/private/ejemplo.com.key
SSLCertificateChainFile /etc/ssl/certs/chain.crt
DocumentRoot /var/www/ejemplo.com
ServerName ejemplo.com
```

## 24.3 Uso de Let's Encrypt

**Let's Encrypt** es una CA gratuita y automatizada.

### 1. Instalar Certbot
```
sudo apt update
sudo apt install certbot python3-certbot-apache
```

### 2. Obtener e instalar certificado automáticamente
```
sudo certbot --apache -d ejemplo.com -d www.ejemplo.com
```

Certbot:
- instala el certificado,
- configura Apache,
- habilita redirección HTTPS.

---

## 24.4 Renovación automática

Los certificados de Let's Encrypt duran **90 días**.

Probar la renovación:
```
sudo certbot renew --dry-run
```

Si la simulación no da errores, la renovación automática está correctamente configurada.

---

## 24.5 Validación del certificado

Para comprobar su funcionamiento:
1. Acceder al dominio con HTTPS desde un navegador.
2. Verificar el candado en la barra de direcciones.
3. Comprobar que:
   - el certificado es válido,
   - corresponde al dominio,
   - no está caducado.

---

## 24.6 Buenas prácticas

- Proteger las claves privadas con permisos correctos.
- Usar siempre HTTPS para sitios con autenticación.
- Mantener actualizados los paquetes de OpenSSL y Apache.
- Habilitar redirecciones HTTP → HTTPS.
