# 20. Instalación de un servidor web

## Objetivos
Adquirir los conocimientos necesarios para instalar un servidor web en un entorno Linux.
Familiarizarse con los paquetes y herramientas de software más comunes para servidores web.
Preparar el servidor para configuraciones avanzadas y despliegue de sitios web.

## 20.1 Requisitos Previos
Antes de proceder con la instalación de un servidor web, se deben cumplir ciertos requisitos:
- Un sistema operativo Linux, preferiblemente Ubuntu Server.
- Acceso de superusuario o permisos para instalar paquetes.
- Conexión a internet para descargar los paquetes necesarios.

## 20.2 Instalación de Apache
El servidor web más utilizado es Apache. Para instalarlo en Ubuntu, sigue estos pasos:

1. Actualiza el índice de paquetes del sistema:
```
sudo apt update
```

2. Instala Apache utilizando APT:
```
sudo apt install apache2 -y
```

Tras la instalación, Apache debería iniciarse automáticamente. Puedes verificar su estado con:
```
sudo systemctl status apache2
```

## 20.3 Prueba del Servidor Web
Para comprobar que el servidor está funcionando correctamente, abre un navegador web y accede a la dirección IP del servidor.

Deberías ver la página de bienvenida de Apache indicando que el servidor está operativo.

Si usas el mismo equipo:
- http://localhost
- http://127.0.0.1

## 20.4 Configuración Inicial
Pasos recomendados tras la instalación:

### Permitir tráfico HTTP y HTTPS
```
sudo ufw allow 'Apache Full'
```

### Verificar directorios por defecto
El contenido web predeterminado se encuentra en:
```
/var/www/html
```

### Habilitar inicio automático
```
sudo systemctl enable apache2
```

## 20.5 Actualización de Apache
Es importante mantener Apache actualizado:

```
sudo apt update
sudo apt upgrade
```
