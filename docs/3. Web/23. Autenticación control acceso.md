# 23. Configuración de mecanismos de autentificación y control de acceso

## Objetivos
- Configurar mecanismos de autentificación para proteger recursos del servidor web.
- Gestionar el control de acceso basado en usuarios y grupos.
- Aprender a utilizar archivos de contraseñas y módulos de Apache para implementar seguridad.

---

## 23.1 Introducción a la autenticación en Apache
Apache permite proteger recursos mediante diferentes métodos de autenticación.  
Los más usados incluyen:
- archivos de contraseñas (`.htpasswd`),
- bases de datos externas,
- autenticación por IP.

El servidor puede solicitar credenciales antes de permitir acceso a determinados directorios.

---

## 23.2 Habilitación del módulo de autenticación

Antes de usar autenticación, activar los módulos necesarios:

```
sudo a2enmod auth_basic
sudo a2enmod authn_file
sudo systemctl restart apache2
```

### **auth_basic**
Permite:
- solicitar usuario y contraseña al acceder a un directorio protegido.

### **authn_file**
Permite:
- validar usuarios mediante un archivo `.htpasswd`.

---

## 23.3 Configuración de un directorio protegido

### 1. Crear un archivo de contraseñas

```
sudo htpasswd -c /etc/apache2/.htpasswd usuario1
```

El sistema pedirá la contraseña del usuario.

Para añadir usuarios adicionales sin sobrescribir:

```
sudo htpasswd /etc/apache2/.htpasswd usuario2
```

---

### 2. Editar la configuración del sitio

En el archivo del sitio dentro de `/etc/apache2/sites-available/`, añadir:

```
<Directory /var/www/mi-sitio/protegido>
    AuthType Basic
    AuthName "Área Restringida"
    AuthUserFile /etc/apache2/.htpasswd
    Require valid-user
</Directory>
```

Esto protegerá el directorio `/protegido` solicitando usuario y contraseña.

---

## 23.4 Prueba de autenticación

Al acceder desde un navegador al directorio protegido, deberá aparecer un cuadro solicitando:
- nombre de usuario,
- contraseña.

Si son correctas, se permitirá el acceso.

---

## 23.5 Control de acceso por IP

Apache permite permitir o denegar acceso según direcciones IP:

```
<Directory /var/www/mi-sitio/protegido>
    Require ip 192.168.1.0/24
    Require not ip 203.0.113.0
</Directory>
```

Ejemplo:
- Permitir solo la red local 192.168.1.x  
- Denegar la IP 203.0.113.0

---

## 23.6 Uso de grupos para control avanzado

### Archivo de grupos `.htgroup`

Crear archivo:
```
/etc/apache2/.htgroup
```

Contenido:
```
admin: usuario1 usuario2
lectores: usuario3 usuario4
```

### Configuración del sitio

```
<Directory /var/www/mi-sitio/protegido>
    AuthType Basic
    AuthName "Área Administrativa"
    AuthUserFile /etc/apache2/.htpasswd
    AuthGroupFile /etc/apache2/.htgroup
    Require group admin
</Directory>
```

Solo los usuarios incluidos en el grupo **admin** tendrán acceso.

---

## 23.7 Notas importantes

- Mantener los archivos `.htpasswd` y `.htgroup` fuera del directorio web.
- Usar HTTPS si se emplea autenticación básica (las contraseñas viajan codificadas pero no cifradas).
- Revisar permisos para evitar accesos indeseados.
