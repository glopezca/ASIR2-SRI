# 27. Documentación de instalación, configuración y recomendaciones de uso de Apache

## 27.1 Instalación de Apache

### En sistemas basados en Debian/Ubuntu
```
sudo apt update
sudo apt install apache2
```

### En sistemas basados en Red Hat/CentOS
```
sudo yum install httpd
```

Es recomendable consultar la guía oficial de instalación para casos específicos o sistemas no derivados de Debian/Red Hat.

---

## 27.2 Archivos principales de configuración

Los archivos principales varían según la distribución:

### Debian/Ubuntu
```
/etc/apache2/apache2.conf
```

### Red Hat/CentOS
```
/etc/httpd/conf/httpd.conf
```

### Sitios virtuales
En Debian/Ubuntu:
```
/etc/apache2/sites-available/
/etc/apache2/sites-enabled/
```

Allí se declaran:
- VirtualHosts  
- directorios raíz  
- parámetros de seguridad  
- logs personalizados  

Consultar la documentación oficial para configuraciones avanzadas.

---

## 27.3 Recomendaciones de uso

### 1. Seguridad

- Desactivar módulos innecesarios  
  ```
  sudo a2dismod nombre_modulo
  ```
- Restringir acceso a directorios sensibles mediante `.htaccess` o config principal.
- Habilitar HTTPS para proteger comunicaciones:
  - revisar guía de SSL/TLS de Apache.

---

### 2. Rendimiento

- Activar compresión Gzip:
  - Usar módulo `mod_deflate`.
- Configurar caché del navegador:
  - Mejorar tiempos de carga.
- Ajustar parámetros del MPM (Multi-Processing Module):
  - Número de procesos,
  - Máximo de conexiones,
  - Hilos por proceso.

---

### 3. Monitorización

Revisar logs de Apache regularmente:

```
/var/log/apache2/error.log
/var/log/apache2/access.log
```

Uso de herramientas:
- **apachetop**
- **goaccess**
- **htop** (para carga del sistema)

## 27.4 Buenas prácticas adicionales

- Dividir configuración en archivos pequeños y organizados.
- Usar `apache2ctl configtest` antes de cualquier reinicio.
- Mantener copias de seguridad de configuraciones críticas.
- Llevar un registro de cambios (CHANGELOG interno).
