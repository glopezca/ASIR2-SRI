# 26. Configuración avanzada con módulos y extensiones

## Objetivos
- Entender el concepto y la utilidad de los módulos en Apache.
- Aprender a habilitar, deshabilitar y configurar módulos adicionales.
- Conocer extensiones comunes y su configuración básica.

---

## 26.1 ¿Qué son los módulos en Apache?
Los módulos son componentes que amplían las capacidades del servidor web Apache.

Pueden ofrecer funcionalidades como:
- reescritura de URLs,
- soporte SSL/TLS,
- manipulación de cabeceras,
- ejecución de código (PHP, Python),
- proxy inverso,
- compresión,
- control de seguridad.

Algunos módulos vienen habilitados por defecto, otros deben activarse manualmente o instalarse.

---

## 26.2 Comandos para gestionar módulos

### **Habilitar un módulo**
```
sudo a2enmod nombre_modulo
```

### **Deshabilitar un módulo**
```
sudo a2dismod nombre_modulo
```

### **Listar los módulos habilitados**
```
apache2ctl -M
```

---

## 26.3 Módulos comunes y su configuración

### 🔹 **mod_rewrite** — Reescritura de URLs

**Activación:**
```
sudo a2enmod rewrite
sudo systemctl reload apache2
```

**Configuración básica:**
```
<Directory /var/www/ejemplo.com>
    AllowOverride All
</Directory>
```

Permite usar `.htaccess` para reescritura de URLs.

---

### 🔹 **mod_ssl** — HTTPS con certificados SSL

**Activación:**
```
sudo a2enmod ssl
sudo systemctl reload apache2
```

**Configuración básica:**
```
<VirtualHost *:443>
    ServerName ejemplo.com
    DocumentRoot /var/www/ejemplo.com

    SSLEngine on
    SSLCertificateFile /etc/ssl/certs/ejemplo.com.crt
    SSLCertificateKeyFile /etc/ssl/private/ejemplo.com.key
</VirtualHost>
```

---

### 🔹 **mod_headers** — Manipulación de cabeceras HTTP

**Activación:**
```
sudo a2enmod headers
sudo systemctl reload apache2
```

**Ejemplo de seguridad:**
```
<IfModule mod_headers.c>
    Header always set X-Content-Type-Options "nosniff"
    Header always set X-Frame-Options "DENY"
</IfModule>
```

---

### 🔹 **mod_proxy** — Proxy inverso y balanceo de carga

Permite que Apache actúe como intermediario para otras aplicaciones.

**Activación:**
```
sudo a2enmod proxy
sudo a2enmod proxy_http
sudo systemctl reload apache2
```

**Ejemplo básico:**
```
ProxyPass /app http://localhost:3000/
ProxyPassReverse /app http://localhost:3000/
```

---

## 26.4 Instalación de módulos adicionales

Ejemplo: módulo PHP para Apache.

```
sudo apt install libapache2-mod-php
sudo systemctl reload apache2
```

Instala el soporte para ejecutar archivos `.php` en Apache.

---

## 26.5 Resolución de problemas relacionados con módulos

### 1. Verificar si el módulo está habilitado
```
apache2ctl -M
```

### 2. Revisar logs de error
```
/var/log/apache2/error.log
```

### 3. Comprobar conflictos de configuración
- Reglas duplicadas
- Directivas incompatibles
- Módulos que requieren otros módulos

### 4. Validar sintaxis
```
sudo apache2ctl configtest
```

Si está correcto:
```
Syntax OK
```

---

## 26.6 Recomendaciones finales

- Habilitar solo los módulos necesarios.
- Deshabilitar módulos no utilizados para mejorar seguridad.
- Revisar actualizaciones de módulos críticos (SSL, proxy).
- Usar logs y `configtest` antes de reiniciar el servicio.
