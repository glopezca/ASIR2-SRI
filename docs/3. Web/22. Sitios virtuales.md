# 22. Creación y configuración de sitios virtuales

## Objetivos
- Comprender el concepto de sitios virtuales y su utilidad en la administración de servidores web.
- Aprender a crear y configurar múltiples sitios web en un solo servidor mediante hosts virtuales.
- Optimizar la gestión de recursos y configurar dominios específicos para cada sitio.

## 22.1 ¿Qué son los sitios virtuales?
Un **sitio virtual** o **host virtual** permite alojar múltiples sitios web en un mismo servidor físico.  
Cada sitio puede contar con:
- dominio propio,
- directorio raíz independiente,
- configuración personalizada.

Esto facilita el alojamiento compartido o el desarrollo de varias aplicaciones en un único servidor.

## 22.2 Tipos de sitios virtuales

### **Sitios virtuales basados en nombre**
Usan **el mismo puerto y la misma IP**, diferenciándose por el nombre del dominio enviado en la solicitud HTTP.

Ejemplo:  
- ejemplo.com  
- tienda.com  
ambos alojados en la misma máquina.

### **Sitios virtuales basados en IP**
Cada sitio utiliza:
- una **IP distinta**,
- o un **puerto distinto**.

Muy útil para configuraciones avanzadas o entornos de pruebas.

## 22.3 Creación de un sitio virtual basado en nombre

A continuación, se muestra cómo crear un sitio para **ejemplo.com**.

### 1. Crear el directorio del sitio
```
sudo mkdir -p /var/www/ejemplo.com
```

### 2. Configurar permisos
```
sudo chown -R $USER:$USER /var/www/ejemplo.com
sudo chmod -R 755 /var/www/ejemplo.com
```

### 3. Crear archivo de configuración del sitio
Editar:
```
sudo nano /etc/apache2/sites-available/ejemplo.com.conf
```

Contenido recomendado:
```
<VirtualHost *:80>
    ServerName ejemplo.com
    ServerAlias www.ejemplo.com
    DocumentRoot /var/www/ejemplo.com

    <Directory /var/www/ejemplo.com>
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/ejemplo.com_error.log
    CustomLog ${APACHE_LOG_DIR}/ejemplo.com_access.log combined
</VirtualHost>
```

### 4. Activar el sitio
```
sudo ln -s /etc/apache2/sites-available/ejemplo.com.conf /etc/apache2/sites-enabled/
```

## 22.4 Creación de sitios virtuales basados en IP

Ejemplo:  
- sitio1 → puerto **80**  
- sitio2 → puerto **8080**

### 1. Crear los directorios de ambos sitios
```
sudo mkdir -p /var/www/sitio1
sudo mkdir -p /var/www/sitio2
```

### 2. Asignar permisos
```
sudo chown -R $USER:$USER /var/www/sitio1
sudo chown -R $USER:$USER /var/www/sitio2
sudo chmod -R 755 /var/www/sitio1 /var/www/sitio2
```

### 3. Configurar los archivos de sitios virtuales

#### **Sitio 1 (puerto 80)**

```
<VirtualHost *:80>
    ServerName sitio1.local
    DocumentRoot /var/www/sitio1

    <Directory /var/www/sitio1>
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/sitio1_error.log
    CustomLog ${APACHE_LOG_DIR}/sitio1_access.log combined
</VirtualHost>
```

#### **Sitio 2 (puerto 8080)**

```
<VirtualHost *:8080>
    ServerName sitio2.local
    DocumentRoot /var/www/sitio2

    <Directory /var/www/sitio2>
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/sitio2_error.log
    CustomLog ${APACHE_LOG_DIR}/sitio2_access.log combined
</VirtualHost>
```

---

## 22.5 Activación del sitio en puertos adicionales

Para habilitar el uso del puerto **8080**, editar:

```
sudo nano /etc/apache2/ports.conf
```

Agregar:
```
Listen 8080
```

Reiniciar Apache:
```
sudo systemctl restart apache2
```

---

## 22.6 Comprobación de la configuración

Validar que la sintaxis es correcta:
```
sudo apache2ctl configtest
```

Si todo está correcto:
```
Syntax OK
```

Reiniciar:
```
sudo systemctl restart apache2
```

---

## 22.7 Notas finales

- Los sitios deben apuntar correctamente desde el DNS o el archivo `/etc/hosts` en entorno local.
- Es buena práctica separar **logs** por sitio.
- Permitir `AllowOverride All` solo si se necesitan `.htaccess`, de lo contrario usar `None` para mayor seguridad.
