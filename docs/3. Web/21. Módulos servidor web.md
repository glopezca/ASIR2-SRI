# 21. Activación y configuración de módulos en un servidor web

## Objetivos
- Comprender el papel de los módulos en el funcionamiento de un servidor web.
- Aprender a activar, desactivar y configurar módulos en Apache.
- Conocer algunos de los módulos más comunes y sus aplicaciones prácticas.

## 21.1 ¿Qué son los módulos?
Los módulos en un servidor web son complementos que extienden su funcionalidad.

Apache permite añadir características como:
- soporte para lenguajes de programación,
- autenticación personalizada,
- redirecciones,
- compresión de archivos, entre otros.

Algunos módulos vienen preinstalados pero desactivados, y otros requieren instalación adicional.

## 21.2 Comandos básicos para la gestión de módulos

### Activar un módulo
```
sudo a2enmod <nombre_modulo>
```
Ejemplo:
```
sudo a2enmod rewrite
```

### Desactivar un módulo
```
sudo a2dismod <nombre_modulo>
```
Ejemplo:
```
sudo a2dismod rewrite
```

### Reiniciar Apache tras cambios en módulos
```
sudo systemctl restart apache2
```

## 21.3 Módulos comunes y sus funciones

### **mod_rewrite**
Permite:
- redirecciones avanzadas,
- reescritura de URL,
- creación de URLs amigables en aplicaciones web.

### **mod_ssl**
Habilita HTTPS mediante certificados SSL/TLS.

### **mod_userdir**
Permite que cada usuario tenga un directorio web en:
```
~/public_html
```

### **mod_headers**
Permite manipular encabezados HTTP.

### **mod_proxy**
Habilita proxy inverso y balanceo de carga.

## 21.4 Configuración de un módulo (ejemplo: mod_rewrite)

1. Activar el módulo:
```
sudo a2enmod rewrite
```

2. Editar configuración del host virtual en:
```
/etc/apache2/sites-available/
```

Añadir:
```
<Directory /var/www/>
    AllowOverride All
</Directory>
```

3. Reiniciar Apache:
```
sudo systemctl restart apache2
```

## 21.5 Verificación de módulos activos
Para listar módulos activos:
```
apache2ctl -M
```
Esto muestra la lista completa de módulos cargados en el servidor.
