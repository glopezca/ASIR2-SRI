# 29. Guía de .htaccess

El archivo **.htaccess** (Hypertext Access) es un archivo de configuración de Apache que permite realizar ajustes específicos para un directorio sin necesidad de editar los archivos de configuración global del servidor.

Se coloca en el directorio que se desea configurar y afecta también a sus subdirectorios.

---

## 29.1 ¿Qué es .htaccess?

El archivo `.htaccess` permite:

- Controlar el acceso a directorios  
- Realizar redirecciones  
- Definir errores personalizados  
- Configurar caché  
- Habilitar compresión  
- Reescribir URLs  
- Añadir reglas de seguridad  

Para que Apache permita su uso, se debe habilitar:
```
AllowOverride All
```

---

## 29.2 Características principales

- Control de acceso basado en autenticación
- Reescritura y redirección de URLs
- Gestión de caché y compresión
- Bloqueo de recursos
- Gestión de errores personalizados

---

## 29.3 Sintaxis básica

La sintaxis de `.htaccess` está basada en directivas de Apache.  
Ejemplo de estructura:

```
<Directory /ruta/>
    AllowOverride All
</Directory>
```

---

## 29.4 Directivas comunes

### 🔹 1. Redirecciones

#### Redirigir una página a otra:
```
Redirect 301 /antigua-pagina.html /nueva-pagina.html
```

#### Redirigir todo el tráfico a otro dominio:
```
Redirect 301 / https://www.nuevo-dominio.com/
```

---

### 🔹 2. Reescritura de URL (mod_rewrite)

Habilitar motor de reescritura:
```
RewriteEngine On
```

Ejemplo:
```
RewriteRule ^pagina/([0-9]+)$ pagina.php?id=$1 [L]
```

Esto convierte:
```
pagina.php?id=123
```
en  
```
pagina/123
```

---

### 🔹 3. Protección de directorios

#### Autenticación básica:
```
AuthType Basic
AuthName "Área restringida"
AuthUserFile /path/a/.htpasswd
Require valid-user
```

Crear archivo `.htpasswd`:
```
htpasswd -c /path/a/.htpasswd usuario
```

---

### 🔹 4. Páginas de error personalizadas

```
ErrorDocument 404 /404.html
ErrorDocument 500 /500.html
```

---

### 🔹 5. Protección contra hotlinking

Evita que otros sitios enlacen tus imágenes:

```
RewriteEngine On
RewriteCond %{HTTP_REFERER} !^$
RewriteCond %{HTTP_REFERER} !^https://(www\.)?tudominio.com/ [NC]
RewriteRule \.(jpg|jpeg|png|gif)$ - [F]
```

---

### 🔹 6. Habilitación de compresión Gzip

Reduce tamaño de archivos enviados al cliente:

```
AddOutputFilterByType DEFLATE text/html text/plain text/xml text/css application/javascript
```

---

### 🔹 7. Configuración de caché

Configurar políticas de expiración:
```
ExpiresActive On
ExpiresByType text/html "access plus 1 day"
ExpiresByType image/jpeg "access plus 1 week"
ExpiresByType application/javascript "access plus 1 month"
```

---

## 29.5 Recomendaciones

- Usar `.htaccess` solo si no se tiene acceso a configuración global.
- Mantener `AllowOverride` lo más restrictivo posible.
- Probar las reglas antes de producción.
- Validar configuración con:
```
apache2ctl configtest
```

---

## 29.6 Conclusión

`.htaccess` es una herramienta poderosa que permite personalizar el comportamiento de Apache en directorios específicos, mejorando:

- seguridad  
- rendimiento  
- funcionalidades  

Su uso adecuado es clave en entornos compartidos o con múltiples aplicaciones.
